This repo contains my personal Neovim setup. Feel free to copy X)

Most of the setup was done my installing and configuring LazyVim on top of Neovim, but
I've also made a lot of changes to fit my personal taste. Some of which include: changing
the title on the home screen (dashboard.lua), adjusting the color scheme to be TokyoNight
with a completely black background (colorscheme.lua), fixing leap (leap_fix.lua), fixing
treesitter (treesitter.lua), adding the live-preview plugin (live-preview.lua) and
adjusting the autocmds.lua file so that .txt documents have a comment-like function
when // # \\ or /* */ is used.
